## Result

- One cow/van SVG family from the Opus consultation, with readable route labels and the Armenia interruption. The handwritten hero link and large closing name remain.
- Homepage gallery with five real projects, current Ollie and Prepped icons, and project screenshots.
- All ten public project routes use a shared Dutch layout, project facts, a personal reason, a concrete action where available, and a next-project link. Icon-led pages have a different header from screenshot-led pages.
- Courses retain one-day, one-to-fifteen, on-location/online facts. The detail pages have lighter programmes, useful course figures, a concrete static export example and a single contextual contact footer.
- Yellow Shop is the verified display name; /yellow-store/ remains. Hiredd has no public code link because its repository is private.

## Limits

The special target remains unmet after the explored SVG, editorial, personal-note/gallery and workshop approaches. The Obsidian homepage image is still a small screenshot. Ollie's fuller mobile page is longer than the original bare text page; its desktop quote leaves some space beside the body. These are recorded tradeoffs, not hidden passes.

Round4's interactive course experiments did not clearly beat D and regressed consistency. Their runtime and tests were removed. The browser-tested experiments and screenshots remain local evidence.

The local comparison artifact is iterate/comparison.html. Large captures and source snapshots remain local and are ignored by Git. The branch is a draft PR, not a deployment.
